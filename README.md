# Just The Recipe

Paste a recipe page (HTML or text) and get only the ingredients and steps — no life story — with a copy button.

Wished by **T1LT3D3412** after people asked for a way to skip the life story and get a clean recipe card.

## Use

Open `index.html` in any web browser. No install or build needed.
